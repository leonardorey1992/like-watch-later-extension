# Contributing

Small fixes and improvements are welcome. For larger changes, open an issue
first so we can agree on the approach.

## Before you open a pull request

- Test the change by loading the extension unpacked and trying it on YouTube.
- Keep the change focused. One fix or feature per pull request.
- By submitting a pull request, you agree to the [Contributor License
  Agreement](CLA.md).

## Development

There is no build step. See the [README](README.md#development) for the file
layout and the reload workflow.
